## About

**Talent Protocol Season 2 Landing Page**

This repository contains the official frontend for **Season 02** of [Talent Protocol](https://talent.app) — the leading web3 professional community for high-potential builders.

Talent Protocol helps builders showcase their on-chain reputation, track real contributions (smart contracts, GitHub activity, etc.), earn rewards from ecosystems, and build their professional network in a transparent and decentralized way.

Built with **Next.js**, **TypeScript**, and modern web technologies, this is the public landing page and web application for Season 2.

### Key Features
- Builder profiles and reputation system
- Real-time contribution tracking (GitHub + on-chain)
- Rewards campaigns and leaderboards
- Fully open-source and community-driven

We believe openness and transparency create a better future for builders. That's why everything is built in public and on a path to progressive decentralization.
